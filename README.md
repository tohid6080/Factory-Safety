# ماجراجویی ایمنی (Factory Safety)

بازی آموزشی ایمنی برای کارخانه خودروسازی، با رابط کاملاً فارسی (React + Vite).

## اجرا
```
npm install
npm run dev
```

## ساخت و بررسی
```
npm run build
npm run lint
```

## روش بازی
- نام و شماره پرسنلی را وارد کنید و توضیحات سرپرست را بخوانید.
- با دکمه‌های جهت (یا کلیدهای جهت‌نما / WASD) وارد ۱۰ منطقه خطر شوید و به سؤال هر منطقه پاسخ دهید.
- از برخورد با همکارانی که در مسیر رفت‌وآمد دارند دوری کنید؛ ۳ جان دارید.
- پس از تکمیل همه مناطق، از خروجی وارد آزمون نهایی شوید (حداقل ۴ از ۵ پاسخ درست).
